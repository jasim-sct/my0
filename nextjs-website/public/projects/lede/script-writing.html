The rules

How we write for video

Three seconds or nothing

The hook is not the first sentence, it is the first image plus the first four words. We write both and mark the timing.

Written to be spoken

Every script is read aloud before delivery. If the presenter runs out of breath, the sentence is wrong.

Timed, not guessed

Word count maps to runtime at roughly 150 words per minute for ads, 170 for explainers. We deliver to the second.

One idea per shot

If a line needs two visuals to make sense, it is two lines. Editors should never have to guess.
