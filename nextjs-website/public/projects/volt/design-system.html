The Volt
design system

Neo-brutalism with rules. Every token, component and decision documented so the next person to touch this does not guess.

01 · Colour

One near-white, one near-black, four electrics. Colour is structural here — it separates regions rather than decorating them.

Contrast rules

  • → Lime and cyan take ink text only — never white.
  • → Violet and pink take white text only — never ink.
  • → Every combination above clears WCAG AA at 16px.

05 · Layout

Spacing scale

4px base. Sections use clamp(48px, 6.5vw, 96px).

Rotation

Cards rotate between −2° and +1° to break the grid. Never more than 2°, never on text-heavy blocks, never on anything interactive that needs precision.

06 · Principles

Five rules we held

Nothing floats

Every surface has a hard border and a hard shadow. No blur, no gradient, no glass. If it is a thing, it has an edge.

Colour is structure

Blocks of colour separate regions. We never use colour purely to decorate a surface that could be white.

Type does the shouting

Headlines run enormous and tight. That is the personality — so the body copy can stay calm and readable.

Motion is mechanical

Things translate and snap. Nothing fades slowly, nothing eases for half a second. 120–250ms, always.

Loud, still legible

Brutalism is not an excuse for AA failures. Every pairing in this system was contrast-checked.

One accent per screen

Lime leads, violet supports, pink warns. Using all three at equal weight turns the page into noise.
